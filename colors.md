# Fittrix Thailand — Color System

## Primary Colors

| Name            | Hex       | Usage                        |
|-----------------|-----------|------------------------------|
| Primary         | `#FFA800` | Accent, CTA buttons, highlights |
| Secondary       | `#6F6AFF` | Secondary accent, badges     |

## Grayscale

| Name            | Hex       | Usage                        |
|-----------------|-----------|------------------------------|
| Black           | `#222222` | Background, text             |
| Dark Gray       | `#333333` | Cards, navbar                |
| Light Gray 01   | `#888888` | Muted text                   |
| Light Gray 01.5 | `#ACACAC` | Borders, placeholders        |
| Light Gray 02   | `#DDDDDD` | Dividers, subtle borders     |

## Purple Tones (Light backgrounds)

| Name                | Hex       | Usage                        |
|---------------------|-----------|------------------------------|
| Purple Background 01| `#F8F7FA` | Section backgrounds (light)  |
| Purple Background 02| `#EBEBF2` | Card backgrounds (light)     |
| Purple Gray         | `#E3E3F7` | Hover states (light mode)    |

## CSS Variables (assets/css/style.css)

```css
--clr-primary:    #FFA800;   /* Primary accent */
--clr-primary2:   #CC8600;   /* Primary hover (darker) */
--clr-secondary:  #6F6AFF;   /* Secondary accent */
--clr-secondary2: #4F4ACC;   /* Secondary hover (darker) */
--clr-black:      #222222;   /* Deepest background */
--clr-dark:       #2A2A2A;   /* Main dark background */
--clr-dark2:      #333333;   /* Card / section background */
--clr-gray-01:    #888888;   /* Muted text */
--clr-gray-015:   #ACACAC;   /* Borders */
--clr-gray-02:    #DDDDDD;   /* Subtle dividers */
```
